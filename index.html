Define a Python object and explain how it stores data?

Python Object - Definition & Data Storage:

In Python, everything is treated as an object , whether it is a number, a string, a list, a function, or even a class. Every object has an identity, a type, and a value. Objects store data in memory, and variables hold references to these objects rather than directly storing the data itself. For example, in x = 10, the integer object 10 is stored in memory and x refers to that object.

An object is a self-contained unit that combines data (attributes) and the operations (methods) that can be performed on that data.

Properties of a Python Object:

Every object in Python has three essential characteristics:

Identity

  • It is a unique identifier for the object.
  • It tells where the object is stored in memory.
  • It can be obtained using the built-in function id().

Type

  • Defines the kind of object.
  • The type determines what operations can be performed on the object.
  • It can be obtained using built-in function type().

Value

  • It is the actual data stored in or represented by an object.
  • For example, if the object is an integer 5, its value is 5.

Example: Identity, Type, and Value of an Object

The following example demonstrates the three essential characteristics of a Python object: identity, type, and value.

# Identity, Type, and Value
x = 30

print("Identity:", id(x))
print("Type:", type(x))
print("Value:", x)

Storing of data using Objects

Python stores objects in a part of memory called the heap. The heap is the memory area where objects are created and maintained during program execution.

When a value is assigned to a variable, Python creates or refers to an object in memory and associates the variable name with a reference to that object.

Variables in Python are references or names that point to objects, not the objects themselves. A variable provides a way to access the object stored in memory.

Example: Object Creation and Reference

This example creates an integer object, a string object, and a list object. The variables refer to these objects.

# Object creation and reference
x = 5
name = "Python"
numbers = [1, 2, 3]

print(x)
print(name)
print(numbers)

Dynamic Typing in Python

Python uses dynamic typing, which means that the type of an object is determined at runtime. Therefore, the same variable can refer to objects of different types during program execution.

# Dynamic typing
value = 10
print(value)

value = "Python"
print(value)

Python automatically manages memory using reference counting and garbage collection, reducing the need for manual memory management by the programmer.

List and briefly explain any four standard types in Python?

Standard Data Types in Python

Python provides several standard data types that are used to store and manipulate data. These types define the nature of the data and the operations that can be performed on it. Four commonly used standard types are Numeric, Sequence, Text, and Mapping.

1. Numeric Types

Numeric types represent numbers and allow mathematical operations.

  • int: Represents integer numbers without a decimal point. Example: 10, -45, 1000.
  • float: Represents floating-point or decimal numbers. Example: 3.14, -0.5, 2.0.
  • complex: Represents complex numbers in the form a + bj. Example: 2+3j, -5+0.6j.
# Numeric Types
a = 10 # int
b = 3.14 # float
c = 2+3j # complex

print(a)
print(b)
print(c)

2. Sequence Types

Sequence types store multiple items in an ordered collection. Elements can be accessed using indexing.

  • list: An ordered, mutable collection. Example: [1, 2, 3, "Python"].
  • tuple: An ordered, immutable collection. Example: (1, 2, 3).
  • range: Represents a sequence of numbers, often used in loops. Example: range(0, 5) produces 0, 1, 2, 3, 4.
# Sequence Types
my_list = [1, 2, 3]
my_tuple = (4, 5, 6)
my_range = range(0, 5)

print(my_list)
print(my_tuple)
print(list(my_range))

3. Text Type

The text type is used to store string data, which is a sequence of characters.

  • str: Represents a Unicode string enclosed in single quotes, double quotes, or triple quotes.

Examples: "Python", 'Hello', """Multiline String"""

# Text Type
name = "Python Programming"
print(name)

4. Mapping Type

Mapping types store data in key-value pairs. Each key is used to access its corresponding value.

  • dict: Represents a collection of key-value pairs. Dictionaries are mutable, and each key must be unique. Example: {"name": "Python", "version": 3}.
# Mapping Type
student = {
"name": "Lakshman",
"course": "B.Sc Computer Science",
"year": 2026
}

print(student["name"])
print(student["course"])

4. Mapping Type

The mapping type stores data in the form of key-value pairs. The commonly used mapping type in Python is dict. Keys must be unique and immutable, while values can be of any data type.

Example: {"name": "Lakshman", "age": 20}

# Mapping Type
student = {"name": "Lakshman", "age": 20}
print(student)
print(student["name"])

Conclusion

Thus, Numeric, Sequence, Text, and Mapping are four standard data types in Python. They help programmers store, organize, and manipulate different kinds of data efficiently.
